How It Works

Each time you run the parser, it processes your bank statement in two stages:

Stage 1 — Load: Reads the ACH batch detailed CSV into an internal lookup table, keyed by transaction amount. This lets the parser match statement debits to their full descriptions.

Stage 2 — Classify: For each transaction in the bank statement:

  • Credits — classified by amount threshold (tour sale vs. restaurant revenue)
  • Card sales (VisaNet / Neonet / Acepta) — Restaurant/Bar Sales
  • Cash deposits — Cash Deposit
  • ACH debits — matched to the detailed ACH lookup by amount
  • Anything unmatched — sent to the Unclassified Log for manual review

Step 1 — Export Your Bank Data

Bank Statement — download from your online banking portal and export as CSV.

ACH Detailed Report — download the transaction-level ACH batch report from your bank and export as CSV. Optional but recommended — this significantly improves debit classification.

⚠  Both files must cover the same date range. The parser matches statement debits to detailed records by amount — if the ranges don't align, the matches won't work.

Step 2 — Paste Data Into the Import Tabs

Import - Statement tab:

Paste the bank statement CSV starting at cell A1 — paste the full raw export including headers. Row 1 = headers, row 2 = first data row.

Import - Detailed tab:

Paste the ACH batch detailed CSV starting at cell A1. Leave this tab empty if you don't have a separate detailed ACH report.

Step 3 — Run the Parser

At the top of the Google Sheet, find the 🔄 Parser menu and click ▶️ Run on Import Tabs.

A summary alert appears when complete, showing:

  • Total transactions processed
  • How many were auto-classified
  • How many went to the Unclassified Log
  • How many detailed ACH records were loaded

Step 4 — Review QB Upload

Open the QB Upload tab. The output columns are:

Column A — Date   Transaction date (YYYY-MM-DD)
Column B — Description   QB category description — enter this in QuickBooks
Column C — Amount   Negative = debit, positive = credit
Column D — Rule ID   Which rule matched (for debugging)
Column E — Raw Description   Original transaction description

Columns A through C are your QuickBooks upload. To download them as a CSV file, go to 🔄 Parser > 📥 Download QB Upload as CSV. A file named qb_upload.csv saves to your Google Drive root folder. Open it in QuickBooks using your normal CSV import process.

Step 5 — Handle Unclassified Transactions

Open the Unclassified Log tab.

For each row: review the raw description and amount, determine the correct QuickBooks category, and enter it directly in the QB Upload tab.

Active Classification Rules

Amount-Based Rules (Credits):

  • DEPOSITO EN EFECTIVO under Q1,500 — Tour Sale
  • DEPOSITO EN EFECTIVO Q1,500 or more — Restaurant and Bar Sales
  • CREDITO ACH under Q1,500 — Tour Sale
  • CREDITO ACH Q1,500 or more — Bank Transfer
  • CREDITO RECEPTOR ACH under Q1,500 — Tour Sale
  • CREDITO RECEPTOR ACH Q1,500 or more — Bank Transfer

Description Pattern Rules:

  • VisaNet / Neonet / Acepta card sales — Restaurant/Bar Sales
  • DEPOSITO EN EFECTIVO — Cash Deposit
  • TRANSFERENCIA DE FONDOS BC — Transfer Between Accounts
  • DEBITO ACH — matched via detailed ACH lookup when available
  • Pago de Empresa Electrica — Electric Bill
  • DECLARAGUATE TESORERIA NAC. — Taxes
  • ND x Rechazos — Fee for returned check

Clearing and Re-Running

To start fresh without re-uploading data, click 🔄 Parser > 🗑️ Clear QB Upload. This clears the QB Upload and Unclassified Log tabs only — your data in the Import tabs is preserved.
